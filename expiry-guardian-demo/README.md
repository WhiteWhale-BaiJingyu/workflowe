## 部署

仓库根目录netlify.toml已设置base=expiry-guardian-demo，构建npm ci && npm run build，发布dist，Node22。无需任何密钥或环境变量。若Netlify已连接本仓库并启用自动部署，推送main后会按其设置构建；部署状态须到Netlify查看。

本地：npm ci，然后npm run dev；生产构建：npm run build。所有three.js依赖打进dist，无外部CDN。

此公开演示版不等于完整本机运营版：无法在线问答、登记库存、提交分析、人工审批或回填。本机版另行保存。
