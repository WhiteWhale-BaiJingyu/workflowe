# 效期卫士 · 导师演示版

只读图形化演示，默认播放真实工作流API录制的模拟样本，不调用在线服务。

## 功能

- 门店A—E各60批，按等级/区域筛选、点击查看批次与审批单。
- 三维卖场、圆端冷柜、商品外形、鸟瞰/近景/第一人称。
- 五镜头讲解；所有经营数字为模拟数据，陈列位置为示意。
- 此版不提供在线分析、库存登记、审批提交或新回填；完整本机运营版另行保留。

样本是工作流真实返回，复盘输入为模拟实验，不是企业经营成绩。移除了录制会话编号，不含密钥、后端地址或登记数据库。

## Netlify从GitHub部署

选择本仓库，Base directory设置为 `expiry-guardian-demo`（此项目所在目录）；构建命令 `npm ci && npm run build`；Publish directory `dist`。无需设置任何密钥或环境变量。

本地：`npm ci`、`npm run dev`。生产：`npm run build`、`npm run preview`。

## 模型和素材

模型由本地three.js程序生成，three.js随构建打包；不使用CDN、品牌标志或照片贴图。
